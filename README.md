# RoxenBot Cloud 🚀

RoxenBot Cloud, Kick yayıncıları için geliştirilmiş çok kullanıcılı (multi-tenant) bulut tabanlı sohbet botu ve OBS canlı widget platformudur.

## Özellikler
- 🤖 Çok Kanallı Kick Sohbet Botu (Centrifugo WebSocket)
- 🔑 Google & Firebase Authentication ile Giriş
- 💎 VIP PRO Özel Bot İsmi & Ücretli Abonelik Yönetimi
- 🎥 Kişiye Özel OBS Canlı Widget'ları (Alertbox, Chat, Goal)
- ⚡ Express & Socket.IO Mimari

## Kurulum ve Çalıştırma
```bash
npm install
npm start
```
Varsayılan port: `3005`
